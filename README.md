# e-plantShopping

## Paradise Nursery

Paradise Nursery is a React-based houseplant shopping application. The application allows users to browse different categories of houseplants, add plants to a shopping cart, adjust quantities, remove items, and view the total cost of their selected plants.

### Features

* Browse houseplants by category
* View plant names, images, and prices
* Add plants to the shopping cart
* Increase or decrease plant quantities
* Remove plants from the cart
* View total items and total cost
* Navigate between Home, Plants, and Cart pages

### Technologies

* React
* Redux Toolkit
* JavaScript
* HTML
* CSS
